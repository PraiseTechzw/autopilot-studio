# Companion, GitHub, and Team Workflow Visual Verification

Desktop and mobile review was completed for the **Integrations** and **Team approvals** screens. The integration page maintains the dark control-plane visual system, clearly separates the GitHub permission receipt from device pairing, and keeps the read-only boundary prominent. The team page retains legible empty states for workspaces, approval rules, inbox items, and team roles without creating false activity data.

On the 375px mobile viewport, the integration and team screens stack in a readable order. Actions remain reachable, card text stays within the viewport, and the green primary controls retain sufficient contrast. The current browser callback example is intentionally accompanied by guidance to replace it with the published Studio domain before connecting GitHub in production.
