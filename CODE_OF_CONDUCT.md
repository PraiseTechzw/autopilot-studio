# Code of Conduct

We are committed to a respectful, collaborative, and harassment-free community. Treat all contributors with professionalism and respect, welcome good-faith feedback, and avoid discriminatory, threatening, or abusive behavior.

Maintainers may remove, edit, or reject contributions and participation that do not meet these expectations. Report concerns privately to the project maintainer using the repository profile contact method.

## Scope

This policy applies to project spaces, issue discussions, pull requests, release discussions, and community events where a contributor represents Autopilot Studio.
